Les quatre partis pris

Une mesure est un nombre

Un 'normal' dans un varchar ne se trace pas en courbe, ne se moyenne pas, ne se compare pas à la base personnelle — et il oblige à décider de ce qui est normal à l'écriture, avant de savoir.

rythmeCardiaque varchar(255) → fc_bpm REAL

La minute et le jour sont deux tables

À 1 240 résidents, la minute fait 1,8 million de lignes par jour. La console ne les lit jamais : elle lit l'agrégat quotidien, calculé une fois la nuit.

mesures à la minute → mesures_jour, 1 240 lignes / jour

Chaque valeur porte sa source

Le prototype affiche huit constantes dont deux seulement sont vraiment mesurées. Sans cette colonne, l'interface ne peut pas le dire honnêtement — et c'est un argument du pitch.

source = mesure · simule · estime

Les paroles n'existent pas ici

La table des conversations n'a qu'un résumé, jamais de texte intégral. Le service d'ingestion refuse en 422 toute charge utile qui en contiendrait un.

conversations.resume — et rien d'autre

Deux défauts dans le SQL du template

FK

Les deux clés étrangères portent le même nom user_posts. MySQL exige qu'un nom de contrainte soit unique dans toute la base, pas seulement dans la table : le second ALTER TABLE échoue. À renommer fk_donnees_user et fk_mental_user.

PK

etatMental n'a pas de clé primaire. Impossible de corriger ou de supprimer une ligne précise.

Les écarts ont été pris sous le mandat donné avec le template — « si ça ne colle pas, modifie le site ou propose-moi quoi changer sur la table ». Le schéma exécutable vit dans db/serveur/01-schema.sql ; db/reference-mysql.sql conserve la version MySQL d'origine.
